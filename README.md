# 🥗 AI Food Waste Reduction Assistant

## 📌 Project Overview

The **AI Food Waste Reduction Assistant** is an AI-powered sustainability web application that helps users reduce avoidable food waste by managing their food inventory, identifying food items that should be used soon, and generating meal suggestions.

The project demonstrates the use of **Generative AI, RAG (Retrieval-Augmented Generation), Agentic AI, and recommendation techniques** to address a real-world sustainability challenge aligned with **UN Sustainable Development Goal 12 – Responsible Consumption and Production**.

## 🚀 Live Demo

🔗 **[Click here to try the live application](https://ai-food-waste-reduction-assistant-c9nb77w7kqpwly6rgihbmy.streamlit.app/)**

## 🚀 Features

* AI-powered food inventory management
* Identifies food items that should be used soon
* Generates meal suggestions using available ingredients
* Provides food-storage guidance
* Provides sustainability recommendations
* Demonstrates RAG-based knowledge retrieval
* Demonstrates an Agentic AI workflow
* Supports food image upload for future computer vision integration
* User-friendly web interface using Streamlit
* Helps promote responsible food consumption

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/Thanvikacham30/AI-Food-Waste-Reduction-Assistant.git
```

### 2. Navigate to the project folder

```bash
cd AI-Food-Waste-Reduction-Assistant
```

### 3. Install the required packages

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python -m streamlit run app.py
```

### 5. Open your browser

Visit:

```text
http://localhost:8501
```

## 🤖 Artificial Intelligence

### AI Technologies

**Generative AI**

Generative AI can be used to create personalized meal suggestions and sustainability recommendations based on the user's available food.

**RAG – Retrieval-Augmented Generation**

The project uses a knowledge base containing food-storage and sustainability information to retrieve relevant information for recommendations.

**Agentic AI**

The system demonstrates an Agentic AI workflow:

```text
User Food Inventory
        ↓
Analyze Food Items
        ↓
Prioritize Food
        ↓
Retrieve Relevant Knowledge
        ↓
Generate Recommendation
        ↓
Display Meal & Sustainability Guidance
```

**Computer Vision**

The application includes an image-upload feature that can be extended with computer vision to automatically identify food items from uploaded images.
